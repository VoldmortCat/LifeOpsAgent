## 源码核实得到的关键事实（供后续复用，避免重复读码）

- **架构**：LangGraph Subagents。主 Agent `main_agent` 全工具绑定 + `should_continue` 条件边；子 Agent Bill/Travel 各自 ReAct 子图，`run_bill_agent()`/`run_travel_agent()` 沙箱执行（每次新建子图实例，messages 从 HumanMessage(query) 起，仅回传最终文本）。
- **持久化**：SqliteSaver 确实在用（main.py + server.py 第 51-56 行），`data/checkpoints/lifeops_checkpoints.db`。recursion_limit 主图 50 / 子图 25。
- **护栏**：`guardrails/critics.py` 的 `ToolCallCritic`（Bill 传 max_total_calls=6、max_same_call=2；默认构造是 8）、`OutputCritic`（禁止话术正则）。
- **MCP**：`tools/maps/baidu_maps_mcp.py`。三个坑已记录：async→sync 包装、threading.Lock 串行化（stdio 单线程）、坐标幻觉三层校验。**注意：只有 3 次重试 + 1s/2s 递增延迟，没有超时熔断**（之前材料里写的 30s 熔断是错的，已修正）。
- **RAG 已迁 Milvus**：`tools/knowledge/knowledge_tools.py` v3 主路径 = Milvus 2.5 服务端混合检索（稠密+内置中文 BM25，WeightedRanker），city partition key + price expr 下推；降级走本地 JSON 快照 → 应用层管线（ChromaDB/numpy + jieba + rank_bm25）。**简历和 README 仍写 ChromaDB，是不一致项。**
- **打分**：final = 余弦语义 + kw_boost + tag_boost + sem_tag_boost。语义标签路由复用主检索查询向量（零额外 API 成本）。CONFIDENCE_THRESHOLD=0.3。
- **Golden Set 实测**（data/rag_eval）：Recall@5 0.7767→0.8067，Hit@5 0.86→0.88，MRR 0.7313→0.7473，**延迟 444.92ms→944.02ms（翻倍）**，bad cases 7→6。分类：按菜系 0.567→0.700（+13.3pp，最大），综合 0.9167→0.8833（**下降**）。
- **上下文控制**：滑动窗口 10 条 + 窗口外 LLM 摘要（≤150字，截断保护 500）+ `_sanitize_messages_for_api` 修复 tool_calls 链断裂（DeepSeek/OpenAI 兼容格式要求）。4 层 Prompt：base→decision→runtime(state开关)→failure。
- **防幻觉三层**：正则聚光灯（数字对照表）→ DATA PANEL（Python 精确计算 + 强制引用）→ OutputCritic。日常开销基线自动排除 >25 元。
- **伪流式**：server.py 第 496 行 `asyncio.to_thread(router.route)` 拿全文后 3 字符切片 + 20ms sleep，非 token 级流式。
