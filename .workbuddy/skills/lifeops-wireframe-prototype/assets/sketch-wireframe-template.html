一、产品介绍

LifeOps 是面向个人的 AI 工具箱：账单导入 → 预算分析 → 出行/消费推荐，多 Agent 协作，数据本地优先。

二、快速上手

1. 在「个人中心」配置邮箱 / 账单导入渠道。
2. 在「智能管家」问「这个月花了多少」→ 自动拉账单分析。
3. 问「周末去哪玩，预算 500」→ 预算约束出行推荐。
4. 在「文档中心」导入文件 → AI 摘要提炼。

三、常见问题

Q：数据存哪？本地优先，导入即归档，不上传第三方。
Q：支持哪些渠道？微信 / 支付宝 / CSV 半自动导入。
