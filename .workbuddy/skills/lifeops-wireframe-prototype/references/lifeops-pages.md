# LifeOps 真实页面结构（用于线框原型保真）

> 提炼自 `LifeOps助手/` 前端源码：`pages.json`、各 `pages/*.vue`、`components/*.vue`。
> 生成线框时，请让每页结构与下列真实布局一致，仅用草图符号表达，不引入真实配色。

## 全局框架

- **TabBar 4 个**：智能管家（首页）· 账单中心 · 文档中心 · 个人中心。选中色 `#007AFF`（线框中用加粗/实心表示 active）。
- **通用顶栏 NavBar**：白底 50px，底部 1px 分隔；左 = 图标+文字（如 📊账单），中 = 标题 + 连接绿点，右 = 头像圆。
- **主色约定（仅作语义标注，线框不填实色）**：支出红 `#dd524d`、收入绿 `#4cd964`、AI 蓝紫渐变 `#007aff→#5856d6`。

---

## 页面 1 · 智能管家（首页，`pages/index/index.vue`）

- 顶栏：`📊账单` ｜ `LifeOps Agent ●` ｜ 头像
- 空状态：居中主标题 + 4 个快捷按钮（查账单 / 出行规划 / 文档总结 / 省钱目标）
- 对话区（有消息时）：
  - 用户气泡：右对齐，蓝紫渐变，白字
  - Agent 气泡：左对齐，白卡，内部依次：**思考过程折叠块**（橙左边框）→ **工具调用卡片**（🔧 tool_name ✅）→ Markdown 正文 → 嵌入式地图
- 底部输入栏 `InputBar.vue`：左语音键 + 中部胶囊输入框 + 右发送圆（蓝）或「＋」

## 页面 2 · 账单中心（`pages/bill/bill.vue` + `components/BillCenter.vue`）

- 统计卡（2 列网格）：本月支出（红）/ 本月收入（绿）/ 结余 / 笔数
- 分类占比：横向条形（每个分类一条，标注金额与占比）
- 明细列表：每条 = 图标 + 主文本 + 灰日期 + 右侧金额（红/绿）
- 抽屉 `BillCenter.vue`：左滑入，宽 84%，含头部标题 + 关闭键 + 与账单中心同构内容

## 页面 3 · 文档中心（`pages/docs/docs.vue`）

- 文档列表：每条 = 标题 + 类型标签 + 元信息（大小/更新时间）
- 文档预览弹窗：标题 + 正文区域 + 关闭键
- 顶部：上传/导入入口 + 搜索框

## 页面 4 · 个人中心（`pages/mine/mine.vue`）

- 用户信息卡：头像 + 昵称 + 一句话简介
- 配置表单分组：
  - 邮箱配置（IMAP 半自动账单导入）
  - 出行偏好（目的地 / 口味 / 预算）
  - 账单导入（微信 / 支付宝 / CSV 半自动）
  - 关于 / 退出登录

## 组件范式（线框可直接复用）

- **统计卡 StatCard**：白卡 12px 圆角，上 12px 灰标签 + 下 20px 加粗数值
- **消息气泡 Bubble**：用户右/渐变，Agent 左/白卡+浅阴影，内含思考块+工具卡+地图
- **抽屉 Drawer**：左滑 84% 宽，含头部+关闭+同构内容
- **输入栏 InputBar**：顶边线，语音键 + 胶囊输入 + 发送圆

---

## 线框语义标注规范（低保真要求）

1. 用**虚线框 + 文字标签**表示图片/地图/图表占位，不画真实图形。
2. 红/绿仅以 `（红）`/`（绿）` 文字或 `[-]`/`[+]` 标注表达收支，不填实色。
3. AI 能力用 `💡 AI` 角标或虚线框标注，区别于普通功能。
4. 保持手绘草图风（见 `assets/sketch-wireframe-template.html` 的 SVG 滤镜）。
