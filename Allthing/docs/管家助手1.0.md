### 🌟 项目名称：LifeOps Agent（个人数字生活运维管家）  
**副标题：** 基于 Event-Driven 与自进化动态知识库的 Autonomous Agent  
### 💡 核心设计哲学  
**“外脑感知 + 内核决策”解耦**：用轻量级后端（Java/Python）做低成本定时监听，仅在“关键事件”（如新岗位发布、价格异动、DDL临近）时，通过 Webhook 异步唤醒 LangGraph 工作流，降低大模型 Token 消耗。  
### 📦 四大核心业务模块（技术栈与用法）  
#### 模块一：主动情报雷达—— 求职/技术动态监控  
**真实痛点**：实习/秋招时，需实时盯紧目标公司招聘动态或开源库更新，手动查看效率低。  
**技术栈与用法**：  
- **定时任务调度**：用 Java Spring Boot 或 Python Crontab 设置每日定时任务，爬取牛客、拉勾、GitHub Releases 等公开平台。  
- **爬虫工具**：封装为 MCP 工具（如 `requests+BeautifulSoup`），Agent 调用获取最新岗位/版本信息。  
- **RAG 与文本匹配**：将 JD/版本更新存入向量库（Chroma/Qdrant），Agent 检索本地“个人简历”“项目经验”文档，计算文本相似度（如 `sentence-transformers`），生成匹配度报告。  
- **Webhook 触发**：当发现新岗位/版本时，通过 HTTP 请求唤醒 LangGraph 工作流，推送“岗位匹配建议”或“版本更新提醒”。  
#### 模块二：行程助手—— 租房/餐饮/交通/旅游规划  
**真实痛点**：异地租房、日常餐饮选择、交通规划、旅游规划时，信息杂乱（中介引流、差评餐厅、交通拥堵），传统 AI 无法积累经验。  
**技术栈与用法**：  
- **MCP 工具调用**：  
  - 爬虫工具（如 `requests+BeautifulSoup` 爬豆瓣租房小组、大众点评、高德地图 API）获取真实经验贴/餐厅信息/交通路线。  
  - 搜索工具（如 SerpAPI）获取旅游攻略、景点信息。  
- **Dynamic-RAG 与 Critic 机制**：  
  - Agent 抓取 10 篇帖子/餐厅信息/交通路线，启动 Critic 节点（用 LangChain 的 `Reflection` 模块），通过“多源交叉验证”（如对比小红书与大众点评评价、高德地图实时路况）丢弃中介引流贴/差评餐厅/拥堵路线。  
  - 将有效信息提取为结构化 Markdown（如《天河区租房避坑指南 v1.md》《广州天河区高性价比餐厅推荐 v1.md》《广州到深圳自驾路线规划 v1.md》），存入本地知识库（Markdown 文件+向量库）。  
- **知识库自进化**：下次用户提问（如“广州天河区预算 1500 租房”“今天想吃大餐，步行 15 分钟内”），Agent 直接检索本地库，回答更精准。  
#### 模块三：个人财务审计与可视化—— 收支分析与决策支持  
**真实痛点**：账单数据杂乱，需了解“钱花在哪、是否超预算”，并基于历史数据给出消费建议（如“想吃大餐时提醒攒钱计划”）。  
**技术栈与用法**：  
- **Code Interpreter**：Agent 调用 Python 工具（如 `pandas`），自动清洗、分类账单 CSV（餐饮、交通、娱乐），计算月度支出趋势。  
- **结构化数据提取与规则推理**：结合用户预设的“每月预算规则”（如“餐饮预算 2000 元”），生成审计报告（如“本月餐饮超支 30%，异常高频消费：‘某某奶茶’25 次”）。  
- **可视化工具**：调用 `Matplotlib` 生成月度收支折线图，直观展示消费趋势。  
- **动态知识库存储**：将审计结果（如《2024年10月财务分析报告.md》）存入本地库，当用户后续有消费决策（如“今天想吃大餐”）时，Agent 检索预算数据和消费习惯，给出建议（如“本月餐饮超支 30%，建议推迟大餐或选人均 50 元以内的餐厅”）。  
#### 模块四：智能会议纪要与上下文感知 DDL 预警—— 会议录音/DDL 管理  
**真实痛点**：会议后忘记关键决策；实习生常忘记 DDL，且重新进入任务状态需回忆历史信息。  
**技术栈与用法**：  
- **语音转文字工具**：封装 `Whisper` 为 MCP 工具，Agent 调用处理会议录音，生成文字记录。  
- **多模态数据拼接**：结合知识库（过往会议风格/术语），生成结构化纪要（议题、结论、待办），推送至用户。  
- **时间触发与上下文检索**：接入日历 API 或本地 Todo List，在 DDL 前两天触发 Agent；Agent 检索本地硬盘/Notion 中的“历史会议记录、废稿代码、参考文档”，生成预警（如“后天交课设，上次卡在数据库死锁，参考 XX 链接，建议优先解决”）。  
### 🛠️ 技术栈全景图  
- **决策大脑**：Python + **LangGraph**（构建带“判断、循环、自省”的状态机工作流）。  
- **动态记忆**：本地 Markdown 文件 + 向量库（Chroma/Qdrant）+ **Critic 评估逻辑**（过滤垃圾数据）。  
- **工具生态**：**FastMCP**（封装爬虫、搜索、语音转文字、可视化、Code Interpreter 等工具，实现逻辑与工具解耦）。  
- **感知调度**：Java Spring Boot/Python Crontab（定时任务）+ Webhook（唤醒 LangGraph）。  
### 🚀 简历高光写法  
> **项目名称：LifeOps Agent - 面向新人的自进化数字管家**  
>  
> **项目背景**：针对个人在求职、行程规划、学业、日常决策中的信息碎片化痛点，设计具备“自主感知与记忆进化”能力的 Agent 系统。  
>  
> **核心贡献**：  
> - **Event-Driven 唤醒机制**：用定时任务监控外部目标，仅在状态变更时触发 LangGraph，降低 Token 消耗 99%。  
> - **带“自省”的动态 RAG**：引入 Critic Agent，通过多源验证确保知识库数据纯净，实现“零人工冷启动与越用越准”。  
> - **MCP 工具集标准化**：将爬虫、语音转文字、可视化等工具封装为标准接口，实现主逻辑与工具解耦。  
> - **全场景生活流打通**：串联“求职监控”“行程规划”“财务审计”“会议纪要”四大场景，验证架构通用性。
